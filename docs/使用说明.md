## 一、工具能做什么

输入**一部影片（MKV）+ 它的字幕**，输出**一条随时间变化的情感曲线**。具体来说：

1. 从 MKV 里取出字幕文本；
2. 按固定频率抽帧，只保留**检出人脸**的帧，并把每帧与它所在时刻的字幕对上；
3. 对每帧做两件事：字幕文本的中文情感打分（SnowNLP）、画面人脸的表情识别（DeepFace）；
4. 把两条信号按时间画成图，另存成 CSV / Excel。

最终得到的是"第几分钟到第几分钟，情绪偏正面还是负面、画面表情是高兴还是悲伤"这样的量化依据。

## 三、安装

### 3.1 Python 环境

需要 Python **3.9 ~ 3.12**（已在 3.12.10 上实测跑通）。

```bash
git clone https://github.com/fenglistenvii-tech/movie-emotion-multimodal-analysis.git
cd movie-emotion-multimodal-analysis

python -m venv .venv
.venv\Scripts\activate            # Windows
# source .venv/bin/activate       # macOS / Linux

pip install -r requirements.txt
```

### 3.2 ffmpeg（只有提取字幕那一步需要）

`ffmpeg.exe` 与 `ffprobe.exe` 合计约 426 MB，超过 GitHub 单文件上限，所以没放进仓库，
而是作为 Release 附件提供。

**方式一（推荐）**：到 [Releases](https://github.com/fenglistenvii-tech/movie-emotion-multimodal-analysis/releases)
下载 `ffmpeg-2026-03-09-full-win64.7z`，解压出两个 exe，放进 `src/` 目录。

**方式二**：自己从 <https://www.gyan.dev/ffmpeg/builds/> 下载，同样取 `bin/` 里的两个 exe 放进 `src/`。

**方式三**：用包管理器装到系统 PATH（脚本会自动找到它）：

```powershell
winget install Gyan.FFmpeg
```

> 用你自己的字幕文件时（`data/subtitles/` 里已有三份），**这一步可以跳过**——只有"从 MKV 里提取字幕"才需要 ffmpeg。

### 3.3 人脸检测模型

`src/blaze_face_short_range.tflite`（224 KB）已随仓库提供，**无需另外下载**。
脚本按当前工作目录查找它，所以请在 `src/` 目录下运行。

### 3.4 DeepFace 权重（首次运行需联网）

第一次做情感分析时，DeepFace 会自动下载约 200 MB 的模型权重到用户目录（`.deepface/`）。
这一步只需一次，之后离线也能跑。

## 四、路线 1：图形界面（推荐）

```bash
cd src
python main_ui.py
```

打开后有两个标签页，**按顺序用**：

### 标签页 1「抽帧与字幕对齐」

| 填写项 | 说明 |
| --- | --- |
| 视频文件 | 你的 MKV / MP4 原片 |
| 字幕文件 | 对应的 `.srt`；可用 `data/subtitles/` 里已提供的，或先用标签页外的脚本从原片提取 |
| 输出目录 | 建议用 `<影片名>.Dataset` 这样的名字，后面结果都放这里 |
| 抽帧频率 | 默认 `0.2` 帧/秒，即**约每 5 秒取一帧**；想要更细的曲线可调大到 `0.5` 或 `1` |

点「开始抽帧」。跑完后输出目录里会有：

```
<输出目录>/
├── dataset.csv      # 每张保留帧的时间戳、对应字幕、人脸数
└── frames/          # 保留下来的人脸帧图片
```

> 抽帧只保留**检出人脸**的帧，所以一步 90 分钟的电影大约得到几百到一千多帧，
> 取决于人脸出现频率与抽帧频率。

### 标签页 2「情感分析」

1. 「数据集目录」选**上一步的输出目录**（里面要有 `dataset.csv` 和 `frames/`）；
2. 「分析范围」可留默认（全程），也可填**起始帧 / 结束帧**只分析某一段——适合精读某个情节；
   结束帧填 `99999` 表示到片尾；
3. 点「开始情感分析」。跑的过程中日志区会显示进度（每 50 帧报一次）。

跑完后界面会直接显示两张情感时间线图，文件也写进了数据集目录。

> 想切回来分析另一段区间：改一下起始/结束帧再点一次即可，**会覆盖**该目录下的
> `dataset_some_analysis.csv` 与两张图，所以不同区间建议复制一份目录再跑。

## 五、路线 2：命令行分步执行

### 步骤 ①：从 MKV 提取字幕

```bash
cd src
python extract_subtitles.py
```

脚本会先列出原片里的所有字幕流，形如：

```
--- 发现的字幕流 ---
0. 索引:3 | 编码:subrip | 语言:chi  🇨🇳 [默认]
1. 索引:4 | 编码:hdmv_pgs_subtitle | 语言:chi  ⚠️图片格式(需OCR)
```

然后输入序号选择要提取的那条。结果输出到视频同目录，得到 `<影片名>.chi.srt`。

**两种需要留意的字幕：**

- `hdmv_pgs_subtitle`（蓝光图片字幕）：**无法直接转文本**，脚本会拦截并提示。
  此时要么改选文本字幕流，要么先做 OCR，要么改用外部 `.srt`。
- 已经是 `subrip` / `ass` / `ssa` 的，脚本用 ffmpeg 原样复制导出，很快。

> 原片路径写在脚本底部的 `MKV_FILE` 变量里，**运行前改成你的路径**。

### 步骤 ②：抽帧 + 字幕对齐

```bash
python extract_frames.py <视频.mkv> <字幕.srt> <输出目录> [抽帧频率=0.2]

# 例如
python extract_frames.py "D:\movie\Titanic.mkv" "..\data\subtitles\Titanic.chi.srt" "..\results\Titanic.Dataset" 0.2
```

> 不带参数直接运行 `python extract_frames.py` 时，用的是脚本底部硬编码的示例路径，
> 记得先改成你自己的（否则会报文件不存在）。

### 步骤 ③：情感分析

```bash
# 全片
python analyze_emotions.py <数据集目录>

# 只分析第 531 ~ 563 帧（局部精读）
python analyze_emotions.py <数据集目录> 531 563
```

一个具体的局部区间例子：

```bash
python analyze_emotions.py "..\results\Titanic.Dataset_泰坦尼克号" 531 563
```

三个脚本都不需要额外参数即可运行，但**脚本底部的默认路径是本机示例，必须替换**。

## 六、路线 3：只想看已有结果

**不用安装任何东西。** 三组实验的结果在
[Releases](https://github.com/fenglistenvii-tech/movie-emotion-multimodal-analysis/releases) 里：

| 附件 | 大小 | 内容 |
| --- | --- | --- |
| `multimodal-emotion-results.7z` | 1.25 GB | 全量，含 1641 张抽帧图 |
| `multimodal-emotion-results-lite.7z` | 10.58 MB | 只要 CSV / xlsx / 情感时间线图 |

解压后得到 `results/`，里面三个目录对应三部影片：

```
results/
├── Titanic.Dataset_泰坦尼克号/      # 泰坦尼克号 (1997)
├── Your.Name.Dataset_你的名字/       # 你的名字。(2016)
└── The.Lychee.Road.Dataset_长安的荔枝/ # 长安的荔枝 (2025)
```

**打开方式：**

1. **看结论** → 进 `完整数据/`，打开 `emotion_timeline_smoothed.png`（平滑趋势图，最适合看整体走向）；
2. **看细节** → 打开 `完整数据/初始数据.xlsx`，每行一帧：时间戳、字幕原文、人脸数；
3. **看某个情节** → 打开 `局部数据/` 里对应的 xlsx 与两张图（区间见下方表格）；
4. **自己做统计** → 用 `完整数据/完整数据.xlsx`，字段含义见[第七节](#七输出文件怎么读)。

**三组实验的局部精读区间：**

| 数据集 | 局部区间 |
| --- | --- |
| `Titanic.Dataset_泰坦尼克号` | 第 531 ~ 563 帧 |
| `Your.Name.Dataset_你的名字` | 第 151 ~ 173 帧 |
| `The.Lychee.Road.Dataset_长安的荔枝` | 第 370 ~ 403 帧 |

> 只要 `*-lite.7z` 就够了——它包含全部图表与数值。完整包多出来的 1.25 GB 全是抽帧图片，
> 只有在你想自己重新分析、或想核对具体画面时才需要。

## 七、输出文件怎么读

### 7.1 每帧一行：`dataset.csv`（6 列）

| 字段 | 含义 |
| --- | --- |
| `id` | 保留下来的帧序号，从 0 开始 |
| `time` | 该帧在影片中的时间戳（秒） |
| `src_frame` | 原视频里的绝对帧号 |
| `img` | 图片相对路径，如 `frames/frame_00000.jpg` |
| `text` | 该时刻的字幕文本（含字号颜色等样式标签，分析时会自动清洗） |
| `faces` | 该帧检出的人脸数 |

### 7.2 加了分析结果：`dataset_full_analysis.csv`（10 列）

在前 6 列基础上追加：

| 字段 | 含义 | 取值范围 |
| --- | --- | --- |
| `text_sentiment_score` | 字幕文本的情感值 | 0 ~ 1，**越接近 1 越正面**，0.5 为中性 |
| `happy` | 画面人脸的"高兴"概率 | 0 ~ 100 |
| `sad` | 画面人脸的"悲伤"概率 | 0 ~ 100 |
| `dominant_visual_emotion` | 该帧的主导表情 | `happy`/`sad`/`angry`/`fear`/`disgust`/`surprise`/`neutral`；`No Face` 表示没检到脸，`Image Missing` 表示图片缺失 |

`dataset_some_analysis.csv` 字段完全相同，只是**只包含你指定的那一段区间**。

### 7.3 两张图

| 文件 | 是什么 |
| --- | --- |
| `emotion_timeline_raw.png` | 原始数据图。三条曲线（文本情感 ×100、happy、sad）逐帧画出来，波动大但信息全 |
| `emotion_timeline_smoothed.png` | 平滑趋势图。对三个序列做窗口 7 的移动平均，看整体走向用这张 |

两张图的横轴都是 `分:秒`，并有一条 50 的水平参考线（中性线）。

### 7.4 Excel 表

`完整数据/` 与 `局部数据/` 下的 `.xlsx` 是把上面这些 CSV 转成的 Excel 版本
（`.csv` 直接打开时中文与精度显示不佳），**数值与同名 `.csv` 完全一致**，只是便于查看与取数。

> `完整数据/` 放的是**全片**结果，`局部数据/` 放的是**指定区间**结果，别混用。

## 八、常见问题

| 现象 | 原因与解决 |
| --- | --- |
| `❌ 文件不存在: E:\movie\...` | 脚本底部的示例路径没改。打开脚本改掉 `MKV_FILE` / `video_path` / `dataset_root` |
| `❌ 找不到模型文件 'blaze_face_short_range.tflite'` | 没在 `src/` 目录下运行。先 `cd src` 再执行 |
| `⛔ 无法直接提取文本！` + `⚠️图片格式(需OCR)` | 原盘是 PGS 图片字幕，ffmpeg 转不了文本。改选文本字幕流、先 OCR，或用外部 `.srt` |
| 首次分析卡很久没反应 | DeepFace 在下载约 200 MB 权重，属于正常，留意网络 |
| `⚠️ 匹配图片较少，请检查 frames/ 中的文件名` | `frames/` 里的图与 `dataset.csv` 的 `id` 对不上。别手动改名或删图，重新抽帧即可 |
| `dominant_visual_emotion` 大量为 `No Face` | 该帧人脸太小或侧脸，DeepFace 没识别出来。属正常，可忽略这些帧做统计 |
| `text` 字段里有一堆 `<font ...>` 标签 | 字幕自带的样式代码，**不影响分析**（分析前会被自动清洗），只是 CSV 里看着乱 |
| `ModuleNotFoundError: No module named 'analyze_emotions'` | 你没在 `src/` 目录下运行 `main_ui.py` |
| 界面起不来，提示没有 PyQt5 | 程序会自动回退到命令行菜单模式；也可 `pip install PyQt5` |
| 想换一段区间重新分析 | 改起始/结束帧再跑一次。**注意会覆盖**该目录下的 `dataset_some_analysis.csv` 与两张图 |

## 九、参数与默认值速查

| 参数 | 位置 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 抽帧频率 | GUI 标签页 1 / `extract_frames.py` 第 4 个参数 | `0.2` 帧/秒 | 越大曲线越细，耗时也越长 |
| 起始帧 / 结束帧 | GUI 标签页 2 / `analyze_emotions.py` 第 2、3 个参数 | 全程 | 结束帧 `99999` = 到片尾 |
| 平滑窗口 | `analyze_emotions.py` 里的 `window_size` | `7` | 只影响平滑图，原始图与 CSV 不变 |
| 人脸检测缩放宽度 | `extract_frames.py` 里的 `target_w` | `320` px | 4K 帧会先缩到 320px 宽再检测，提速用 |
| 情感中性线 | 绘图时固定 | `50` | 图上那条灰色参考线 |
