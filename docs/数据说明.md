## 一、数据包里有什么

解压 Release 附件后得到 `results/` 目录，内含三组完整实验结果：

| 目录 | 影片 | 全片分析 | 局部精读区间 | 抽帧图 |
| --- | --- | --- | --- | --- |
| `Titanic.Dataset_泰坦尼克号` | 《泰坦尼克号》Titanic (1997) | ✅ | 第 531 ~ 563 帧 | 1008 张 |
| `Your.Name.Dataset_你的名字` | 《你的名字。》Your Name. (2016) | ✅ | 第 151 ~ 173 帧 | 195 张 |
| `The.Lychee.Road.Dataset_长安的荔枝` | 《长安的荔枝》The Lychee Road (2025) | ✅ | 第 370 ~ 403 帧 | 438 张 |

每个数据集目录的内部结构一致：

```

├── dataset.csv                 # 抽帧记录（extract_frames.py 产出）
├── dataset_full_analysis.csv   # 全片情感分析（analyze_emotions.py 产出）
├── dataset_some_analysis.csv   # 局部区间情感分析（analyze_emotions.py 产出）
├── frames/                     # 抽帧图像，1641 张合计约 1.28 GB
├── 完整数据/                    # 全片汇总
│   ├── 初始数据.xlsx            #   dataset.csv 的 Excel 版（人工汇总）
│   ├── 完整数据.xlsx            #   全片分析结果的 Excel 版（人工汇总）
│   ├── emotion_timeline_raw.png      # 全片原始数据图
│   └── emotion_timeline_smoothed.png # 全片平滑趋势图
└── 局部数据/                    # 局部情节精读
    ├── 局部数据（起止帧）.xlsx   #   局部结果的 Excel 版（人工汇总）
    ├── emotion_timeline_raw.png
    └── emotion_timeline_smoothed.png
```

## 二、处理链路

```
原片 MKV ──extract_subtitles.py──▶ .srt 字幕
   │
   └──extract_frames.py──▶ frames/*.jpg + dataset.csv
                                │
                                └──analyze_emotions.py──▶ dataset_full_analysis.csv
                                                          dataset_some_analysis.csv
                                                          emotion_timeline_*.png
```

其中 `extract_frames.py` 先用 MediaPipe BlazeFace 做**人脸门控**，只保留检出人脸的帧；
`analyze_emotions.py` 对每帧做 SnowNLP 文本情感 + DeepFace 表情识别，再做窗口为 7 的
滑动平均并绘图。

## 三、字段含义

`dataset.csv`：

| 字段 | 含义 |
| --- | --- |
| `id` | 保留下来的帧序号，从 0 开始 |
| `time` | 该帧在影片中的时间戳（秒） |
| `src_frame` | 原视频中的绝对帧号 |
| `img` | 图像相对路径，如 `frames/frame_00000.jpg` |
| `text` | 与该时间戳匹配的字幕文本（含 ASS 样式标签，分析时自动清洗） |
| `faces` | 该帧检出的人脸数量 |

`dataset_full_analysis.csv` / `dataset_some_analysis.csv` 在此基础上追加：

| 字段 | 含义 |
| --- | --- |
| `text_sentiment_score` | SnowNLP 文本情感值，0~1，越接近 1 越正面；空文本为 0.5 |
| `happy` / `sad` | DeepFace 输出的「高兴」「悲伤」概率，0~100 |
| `dominant_visual_emotion` | 该帧主导表情；异常时为 `No Face` / `Image Missing` |

## 四、使用方式

解压后把 `results/` 放到仓库同级目录，即可直接用仓库里的脚本复现或继续分析：

```bash
# 重新分析某一区间（会覆盖该目录下的 dataset_some_analysis.csv 与两张时间线图）
cd src
python analyze_emotions.py <解压后的数据集目录> 531 563

# 从抽帧图重新做全片分析
python analyze_emotions.py <解压后的数据集目录>
```

只想看结果的话，直接打开 `完整数据/`、`局部数据/` 下的 PNG 与 xlsx 即可，无需安装依赖。

## 五、数据说明与已知问题

### 已整理统一的部分

三组结果的数据维度完全一致，且已做过如下整理：

| 项目 | 状态 |
| --- | --- |
| 三案例的文件构成 | ✅ 统一为 `dataset.csv` + `dataset_full_analysis.csv` + `dataset_some_analysis.csv` + `完整数据/` + `局部数据/` |
| 表头与列数 | ✅ `dataset.csv` 6 列；分析结果 10 列，三案例完全一致 |
| xlsx 工作表名 | ✅ 统一为 `dataset` / `dataset_full_analysis` / `dataset_some_analysis` |
| CSV 编码 | ✅ 统一为 UTF-8（带 BOM） |
| 数据完整性 | ✅ 三案例 `id` 均从 0 连续编号：Titanic 0~1007、Your.Name 0~194、长安的荔枝 0~437 |
| 早期遗留目录 | ✅ 已删除 `Your.Name.Dataset_你的名字/1/`（那是失败的早期运行，`dominant_visual_emotion` 整列为 `None`） |
| xlsx 文档属性 | ✅ 已清除作者/最后修改者字段（原为个人 Windows 用户名） |

### 仍需注意的部分

1. **`*.xlsx` 不是脚本产出的**：`analyze_emotions.py` 只写 CSV 与 PNG；xlsx 是事后人工
   汇总整理，单元格的数字格式与 CSV 略有差异（例如 CSV 的 `time` 写作 `546.0`，
   xlsx 里是 `546`），但数值一致。**以 CSV 与 PNG 为脚本原始产出。**

2. **字幕已做过广告清理，且未改动任何时间戳**：三份字幕中被整条删除了片头的发行方署名与
   网址条目（《长安的荔枝》4 条、《你的名字。》1 条），删除时只删整条、不动其余条目的
   时间码，因此字幕与抽帧图片的时间对齐关系保持不变。相应地，被删字幕覆盖的那几帧，
   其 `text` 字段由广告文本变为空字符串，`text_sentiment_score` 由偏离中性的值变为
   中性值 `0.5`；被删条目都位于影片开头 30 秒内。

3. **抽帧图为 4K 截图**，单张平均约 900 KB，因此完整数据包约 1.3 GB；只要图表数值的话
   用轻量包（约 17 MB）即可。
